# Notes (optional)

Meeting notes, logbook and literature notes in Markdown. Use them as much or as little as you like, or delete this folder.

Edit them in any editor or on github.com, or open **this folder** (`notes/`, not the repository root) as a vault in [Obsidian](https://obsidian.md).

| Folder | One file per | File name |
|---|---|---|
| `meetings/` | meeting with your tutor | `YYYY-MM-DD.md` |
| `logbook/` | working day | `YYYY-MM-DD.md` (Obsidian: *Open today's daily note*) |
| `literature/` | paper, book or datasheet | `firstauthor-year-keyword.md` |
| `attachments/` | pasted image (automatic) | |
| `templates/` | note templates (Obsidian: *Templates: Insert template*) | |

Obsidian is preconfigured so pasted images land in `attachments/` and links are standard relative Markdown links, so everything also renders on github.com.

## Literature notes: topics and relations

- **Topics**: list them in the note's `tags` property (`ble`, `low-power`, `lora`...). Reuse the same few tags;
  the Tags pane lists every note per topic.
- **Relations**: under *Related*, type `[[` and pick another note; Obsidian inserts a normal Markdown link.
  Say how they relate (extends, compares, contradicts). Links also work from meeting or logbook notes.
- **See the map**: Graph view shows notes as dots and links as lines (colour by tag in its settings);
  Backlinks lists the notes that point to the current one.
- Name the file like the BibTeX key of the report (`firstauthor-year-keyword`) so notes and citations match.

These notes become public at the defense: write them factually.
